# 计划与决策变更记录

用于记录影响范围、排期、玩法、架构和科学表达的决定。日常完成任务记录在 [工作清单](BACKLOG.md)。

## 2026-10-20 · v0.1 · 初始文档

### 已明确的方向

- 一人开发，暂不考虑商业化。
- 目标收紧为三个月内完成首个鸟种与扩展框架。
- 以北京雨燕作为首篇规划对象。
- 用六章精选鸟生承载成长、迁徙、繁殖与人鸟关系。

### 当前建议，待实施验证

- 按每周 25—35 小时、12 周规划。
- 首版 30—45 分钟，约 20—24 个事件、四套场景和一套飞行互动。
- 使用 TypeScript、Phaser、Vite 与本地存档；React 按熟悉程度决定。
- 桌面优先，手机基本适配。
- 第 10 周通过内部第二物种片段验证扩展能力，不承诺第二个正式篇章。

### 范围取舍

- 推迟开放世界、复杂生态、多代繁衍、账号后端和复杂内容工具。
- 首版优先完整体验，重度自然生存模式后置。
- 存档导入导出及完整离线能力后置。

### 原因

将首版规模与一人三个月的投入匹配，优先完成可玩流程，并通过实际接入验证框架，降低过度设计与内容膨胀风险。

## 2026-10-25 · v0.2 计划 / v0.1.0 原型

- 开始实际开发，采用 TypeScript、Phaser 3.90.0、Vite 6.4.5、原生 DOM/CSS 与 IndexedDB。
- 不引入 React，不接入账号、后台或公开部署。
- 实现六章 20 个事件、程序插画、共用飞行、暂停与辅助完成、图鉴、回忆及自动存档。
- 用顺序章节加局部选择差异验证框架；暂不模拟死亡，也不承诺正式篇章时长。
- 新增 10 项核心／存档测试和内部地面觅食配置，验证流程复用。
- 首次繁殖前明确跳过非繁殖年份；具体年龄暂以约四年的叙事编排，仍待北京种群审核。
- 构建与本地 HTTP 检查通过；浏览器操作被工具策略拦截，视觉、手感与真实设备尚未验收。
- 新增开发说明、阶段进展与事实台账，更新工作清单。

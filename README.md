# 若我为鸟

一款从鸟的视角体验成长、迁徙、繁殖与环境变化的独立网页游戏。项目名称暂定。

当前按**一人开发、暂不考虑商业化、12 周完成北京雨燕首篇及可扩展框架**规划。

## 在线试玩与源码

- [GitHub Pages 演示](https://cppiod.github.io/if-i-were-a-bird/)（已于 2026-10-27 发布）
- [GitHub 源码](https://github.com/cppiod/if-i-were-a-bird)

每次推送到 main，GitHub Actions 会先测试、构建，再部署 dist/。部署说明见 [开发说明](docs/DEVELOPMENT.md#github-pages-部署)。

## 运行初版

需要 Node.js 22.16 或更高的兼容版本。首次安装后运行：

```powershell
npm ci
npm run dev
```

打开终端打印的本地地址（默认 http://127.0.0.1:5173/）。请通过服务器访问，不要直接双击 index.html。

```powershell
npm test
npm run build
```

当前 v0.1.0 为六章、20 个事件的流程原型，约 10—15 分钟仅为体验估计，尚未经首次玩家计时。包含飞行、辅助完成、图鉴、回忆及 IndexedDB 自动存档。未加入音效，不模拟死亡；科学审核和浏览器真机验收尚未完成。

## 使用约定

1. 项目计划保存当前认可的方案；其中标为“建议”或“待确认”的内容尚未最终决定。
2. 日常任务在工作清单中更新，完成后勾选。
3. 影响范围、工期、核心玩法或架构的调整，先更新项目计划，再记录变更原因。
4. 鸟类知识与游戏表达分开记录；新增物种时逐种核实，不直接套用其他鸟的习性。

初始代码开发始于 2026-10-25。12 周计划作为后续迭代参照，实际每周投入时间仍待确认；当前原型完成不代表正式篇章已验收。

# If I were a bird · 若我为鸟

一款从鸟的视角体验成长、迁徙、繁殖与环境变化的独立网页游戏。项目名称暂定。

当前按**一人开发、暂不考虑商业化、12 周完成北京雨燕首篇及可扩展框架**规划。

## 运行初版

需要 Node.js 22.16 或更高的兼容版本。首次安装后运行：

```powershell
npm ci
npm run dev
```

打开终端打印的本地地址（默认 http://127.0.0.1:5173/）。请通过服务器访问，不要直接双击 index.html。

```powershell
npm test
npm run build
```

当前 v0.2.0 按介绍、求偶、筑巢、孵化、养育、飞行、迁徙、回家组织，包含 21 个事件、3 个照料分配任务和可重试失败。以成鸟为主，飞行阶段明确切换幼鸟视角。21 个形态与行为位置有意留白，支持图片、声音、视频上传；上传只保存在当前浏览器，不自动公开。旧版进度独立保留，新结构使用新进度。时长、平衡、真机表现与科学内容仍需后续审核。

## 使用约定

1. 项目计划保存当前认可的方案；其中标为“建议”或“待确认”的内容尚未最终决定。
2. 日常任务在工作清单中更新，完成后勾选。
3. 影响范围、工期、核心玩法或架构的调整，先更新项目计划，再记录变更原因。
4. 鸟类知识与游戏表达分开记录；新增物种时逐种核实，不直接套用其他鸟的习性。

初始代码开发始于 2026-10-25。12 周计划作为后续迭代参照，实际每周投入时间仍待确认；当前原型完成不代表正式篇章已验收。
